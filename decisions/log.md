## first-run 결과 (2026-10-04)

autelon 플러그인의 `playbooks/first-run.md` 를 돌린 결과다. 실제로 본 것만 적는다. 저장소를 로컬 `autelon` 폴더 아래로 옮긴 뒤, 그 폴더에서 연 Desktop Code 세션에서 돌렸다.

| 단계           | 결과                                                                                                                                                                                                                                                                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 준비           | 세션의 Remote Control 켜짐. 플러그인 스킬·공용 role 이 세션에 로드됨. 셸에 `claude` 명령이 없어 `claude plugin list` 는 확인하지 못함. "Push when actions required" 설정은 이 세션에서 읽을 수 없어 확인하지 못함                                                                                                                                        |
| 1. role 인식   | 통과. 프로젝트 role 14개와 `autelon:finance`·`autelon:notion-sync`·`autelon:security-reviewer` 가 subagent 목록에, `autelon:director`·`autelon:found-company` 가 스킬 목록에 있음. 프로젝트 폴더가 아닌 곳에서 시작한 세션(도입 세션)에서는 프로젝트 role 이 보이지 않았음                                                                               |
| 2. 승인 루프   | 통과(재시험 뒤). 첫 시험에서는 폰에서 고른 답은 들어왔지만 푸시가 오지 않았다. 같은 세션에서 `PushNotification` 이 "터미널이 활성 상태라 중복"으로 거절됐다. 사람이 Desktop 앱을 벗어난 뒤 다시 보내자 알림과 AskUserQuestion 푸시가 둘 다 폰에 왔고 폰에서 고른 답이 세션에 들어왔다. 앱을 보고 있으면 푸시가 나가지 않는다(autelon/company#11 에 전달) |
| 3. finance     | 통과. `get_usage` → `state/quota.json`(git 제외 확인) → 판정 스크립트 `GO` → `autelon:finance` 가 `handoffs/T-SMOKE-1.md` 를 씀. 메모리는 `.claude/agent-memory/autelon-finance/` 에 생김(git 제외 확인). 지시문에 "메모리 경로를 그대로 적어라"고 해서 handoff 에 로컬 절대 경로가 들어감 → 앞으로 경로는 프로젝트 기준 상대 경로로 받는다              |
| 4. notion-sync | 통과. `autelon:notion-sync` 가 Notion 커넥터(`notion-create-pages`)로 Milestones DB 에 `M-00` 을 만들고 `notion/ids.json` 에 기록. handoff 에 URL·ID 없음. 사람이 Notion 에서 페이지를 확인하고 지웠다                                                                                                                                                   |
| 5. developer   | 생략. 첫 구현 task 때 확인한다(handoff 가 메인 checkout 절대 경로에 생기는가, `.claude/agent-memory/developer/` 위치)                                                                                                                                                                                                                                    |
| 6. 정리        | 스모크 handoff 두 개와 `board/milestones.json` 의 `M-00` 은 지웠다. Notion 의 `M-00` 페이지는 사람이 지운다. autelon/company 의 `docs/design.md` 7절 갱신은 사람에게 알렸다                                                                                                                                                                              |
